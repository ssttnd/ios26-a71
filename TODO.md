# iOS 26 на Galaxy A71

- [x] **Чёрные полосы сверху и снизу.** Образ `a71-ios26-full-panel.img` заполняет панель 1080×2400. Журнал показал `pad 0,0`, владелец подтвердил результат. Использовать `--fb-scale 2` в следующих тестах. Масштабирование слегка растягивает картинку по вертикали.
- [x] **Зависание «Настроек».** Патч 2118 публикует `IONetworkStack` до запуска `configd`. USB-журнал подтвердил успешное подключение `configd`; владелец подтвердил, что «Настройки» работают. [Сборка ядра](https://github.com/ssttnd/ios26-a71/actions/runs/44583376344)
- [ ] **Штатные динамические обои iOS 26.** В `com.apple.MercuryPoster` штатный набор называется `space.*`. Проверить вариант Sky (`space.two`) на экране блокировки и рабочем столе.
- [x] **Обои и стекло в обоях (2026-11-23).** Размер мип-уровня при записи (328065b) и прямая альфа для depth-прохода (5b102f2): владелец подтвердил обои, цвета и часы.
- [ ] **Прозрачности Liquid Glass.** Добавлена поддержка представлений mip-уровней в SweetNativeMetal. Дождаться [сборки Metal](https://github.com/ssttnd/ios26-a71/actions/runs/44584865459) и проверить размытие в доке, поиске и Пункте управления. В build 36 запросы на BGRA8 mip 1 возвращают `nil`. Замерить плавность отдельно от корректности эффекта.
- [ ] **Dynamic Island.** Уточнить, как SpringBoard задаёт `exclusionArea` для дисплея A71 (414×896 pt). Предыдущий тест MobileGestalt откатан после красной строки состояния. После изменений проверить положение выреза, системные значки и Live Activities.
- [ ] **GPU для всех процессов.** Сейчас Metal получают только `backboardd` и до 3 процессов из списка (с 2138: до 6 через `sweetm2window=128`, имена через `sweetmtlextra`). Причина — одна общая таблица страниц GPU и фиксированные окна адресов на клиента (0x80000000..0xb0000000) плюс 8 общих слотов задач. Шаг 1: по логу отказов (2138) понять, кому GPU нужен, и разрешить их. Шаг 2 при нехватке: динамические окна (меньше размером, только пока процесс жив). Полное решение: своё адресное пространство GPU у каждого процесса (свои таблицы страниц с переключением), как в обычном драйвере.
- [ ] **Иконки.** С GPU для `iconservicesagent` (`sweetmtlextra`, ядро 2138+) все иконки стали жёлтыми квадратами: рендерер иконок (RenderBox) просит текстуру поверх `MTLBuffer` (`Could not make MTLTexture referencing MTLBuffer`), наш SweetNativeMetal её не умеет. Нужно реализовать `-[MTLBuffer newTextureWithDescriptor:offset:bytesPerRow:]` в userspace Metal, потом проверить обычные и «Прозрачные» иконки. Без GPU у `iconservicesagent` «Прозрачные» иконки — пустое стекло.
- [ ] **Виджеты — белые плашки.** Не GPU: `WidgetRenderer_Default` пишет `ChronoKit.CacheManagementError.extensionNotFound` для расширений виджетов (Погода, Новости, Карты, Акции, Советы, Календарь…), содержимого нет. Выяснить, почему ExtensionKit/LaunchServices их не находит (регистрация расширений в корне).
- [ ] **SpringBoard с GPU падает.** С `sweetmtlextra=SpringBoard` — цикл перезагрузок: SiriUICore при старте создаёт фильтр MetalPerformanceShaders, MPS проверяет семейство GPU, наш драйвер заявляет только Apple1 → `MTLReportFailure` → abort. Нужен более высокий профиль (`metal_profile`/supportsFamily) с тем, что реально работает, или обход в Siri.
- [ ] **Обои то есть, то нет.** Mercury рисует кадры, но на части загрузок обоев (и виджетов) нет; после перезагрузки iOS из меню они появляются. Найти причину через `a71:kill:` (2137) и сделать так, чтобы обои загружались всегда.
- [ ] **Bluetooth.** Чип WCN3988 поднимается (прошивка из стока A71, `--bluetooth`). 2136 отбрасывает вендорские события Qualcomm (работает), но `bluetoothd` всё равно падает на `bcm_vsc.c:1021 ByteStream_NumReadBytesAvail >= 4` — значит, короткий ответ на какую-то команду Broadcom. Следующая загрузка: `sweetbtlog=2000`, найти команду и дополнить compat в `sweet_bt_hci.c`. Также TCC: `Unable to construct an identity to kTCCServiceBluetoothAlways`. После этого — зависание «Настроек» при уходе в фон (CoreBluetooth ждёт `bluetoothd`), поиск и подключение устройств.
- [ ] **HFS корня.** Том без журнала; ядро при укорачивании файлов оставляет лишние overflow-экстенты (повреждения появляются даже после чистой перезагрузки). В загрузке 27.11 ещё и `VolumeAllocation.c:3362` и `hfs_vnops.c:4328` (ошибка освобождения блоков при удалении файла). Исправить в `sweet_hfs`, позже — журнал. Пока: после сбоев проверять том `a71-hfs-scan.py` + `fsck -n` (через loop с размером тома).

## Найдено в журнале 27.11 (загрузка bt3 после перезагрузки iOS)

- [ ] **Вылет при долгом нажатии на обои экрана блокировки.** Редактор обоев (PosterBoard) получает третий GPU-слот, и у Mercury отправка на GPU падает с `submit failed: -16 (Resource busy)`, `backboardd` ждёт слот 209×0,5 мс. Причина — 8 общих слотов задач GPU. Исправление 2139 (24 слота) собрать и проверить.
- [ ] **Медленный GPU.** 109 «slow fence» за ~15 мин, у `backboardd` задержка завершения до 0,7 с. Проверить после 2139; искать, что держит GPU (частота, LLCC, размер работы).
- [ ] **Процессы в бесконечном перезапуске.** За ~15 мин: `watchdogd` 101 раз, `wifip2pd` 100, `seputil` 70, `bluetoothd` 17, `sweetposterset` 9 (наша задача). Тратят CPU и память. Для каждого найти, почему выходит (watchdogd — `wdt_test=no_user_checkin`; wifip2pd — нет Wi‑Fi в этом образе; seputil — нет SEP) и либо дать то, что нужно, либо убрать задачу из launchd.
- [ ] **MessagesBlastDoorService падает** (9 раз, SIGTRAP в Swift `assertionFailure` внутри BlastDoor.framework). Нужен его os_log (`sweetdtlog=MessagesBlastDoorService`), чтобы понять, какое условие не выполнено. Влияет на Сообщения.
- [ ] **Safari падает при запуске** (2 раза, неперехваченное ObjC-исключение, `abort` из libc++abi). Нужен os_log MobileSafari для текста исключения.
- [ ] **SpringBoard без Metal.** Пишет «native A618 backend unavailable»: его собственная отрисовка через Metal (иконки, эффекты) идёт без GPU. Решить вместе с пунктом «GPU для всех процессов».
- [ ] **Экран при «выключении» не гаснет полностью.** При сне драйвер (`AppleCLCD::blackout`) только заливает кадр чёрным, панель остаётся включённой. На выключенном экране светится красная точка 2×3 пикселя внизу по центру: она есть в самом кадре (USB-скриншот `build/shot-screen-off.png`, цвет 255,0,0 со светлым центром), в коде ядра такого маркера не нашлось — рисует, видимо, iOS. Нужно: при выключении посылать панели DCS display off / sleep in (меньше расход, нет риска выжечь пиксель) и выяснить, что это за элемент.
- [ ] **Шум в журнале, не ошибки.** «not in trust cache» (84, нормально для нашего ядра), «unnest of DYLD shared region» (у каждого процесса), IOKit не находит `IOAcceleratorES`/USB/Thunderbolt у `backboardd` (59 раз ищет GPU по старому имени), ENOENT на файлы настроек и логирования. Оставить; убрать поиск `IOAcceleratorES`, если он тормозит.
- [ ] **Wi‑Fi.** Подготовлен образ 2119 с узлом `wlan` и пакет с `wland` из рабочего порта A71. Проверить запуск модема, появление `en0`, сканирование и подключение к сети.
